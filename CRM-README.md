# Vaani CRM — your lead manager

A small app that runs **only on your computer**, in your browser, for
managing the leads Vaani scrapes. Excel was never built for follow-ups,
remarks and daily call lists — this is.

**Your existing data comes with you.** The CRM uses the same database
as Vaani (`vaani_master.db`), so every lead you have ever scraped is
already inside. The first time it runs, it also pulls in your Excel
tracker history — outcomes, notes and callback dates — so nothing you
already worked on is lost.

## Install — 2 minutes, one time only

1. Unzip this package **into the same folder as vaani.py** — the
   folder that contains `vaani_master.db` and `vaani-call-tracker.xlsx`.
   (If Windows asks, allow replacing files of the same name.)
2. That's it. No installs — if Vaani runs on this PC, the CRM runs.
3. When it starts, the CRM opens in **Google Chrome as its own app
   window** (no tabs, no address bar) if Chrome is installed —
   otherwise in your default browser. To force the default browser
   instead, run it once from a terminal with `--browser=default`.

The updated CRM UI is served by the same Python process and reads the
SQLite database directly. Status changes, follow-up dates and notes are
written back to the database, so the new interface and the existing Vaani
scraper share one source of truth.

## Daily use

- Double-click **`run-crm.bat`**. Your browser opens at the Dashboard.
  Keep the black window open while you work; close it when done.
  Tip: press **Ctrl+K** anywhere to jump to search.
- **Dashboard** — a greeting, your headline numbers, a visual funnel,
  and today's + overdue follow-ups front and centre. The Follow-ups
   menu item shows a red badge when anything is due.
- **All leads** — a faster searchable workspace with score, tier, source,
  status and follow-up filters. Click a lead to open the drawer, add notes,
  change its status or schedule the next action without leaving the list.
- **Report & WhatsApp kit** — inside every eligible Restaurant or Healthcare
  lead, generate the one-page report, preview it, download the brochure,
  view the prepared message, or send the complete kit automatically through
  WhatsApp Web. The send order is message, report card, then brochure where
  applicable, and each send is logged in the local database.
- **Pipeline** — drag leads between New, Contacted, Interested, Demo, Won
  and Lost. The change is saved into the same SQLite CRM state immediately.
- **Import runs** — shows the scrape dates already present in the database.
  New scraping still runs through `py vaani.py`; reopen the CRM afterward to
  see the new records.
- **Call Mode** — the fastest way to work the day: one lead at a time
  (overdue first, then due today, then fresh A/B leads), big Call and
  WhatsApp buttons, a quick remark box, and one-tap outcomes
  (No answer → retry tomorrow, Callback → +2 days, Interested,
  Demo booked...). It moves to the next lead on its own.
- **Send Kit** (v1.3; auto-send added in v1.4) — warm up leads
  before you call them. The page lists your top 30 pitchable leads
  who haven't received the kit yet (chains and other don't-pitch
  leads are kept out automatically). **Auto-send kit** is the main
  button: it opens WhatsApp Web in a Chrome window and sends, in
  order, the personalised intro message, his report card and the
  brochure (`book-my-food-brochure.pdf`, keep it in this folder),
  then logs it and sets tomorrow's follow-up itself. The first time,
  scan the QR code in that window with your phone (WhatsApp >
  Linked devices) — later sends are one click. The plain **WhatsApp**
  button is the manual way: message prefilled, you attach the files,
  then **Mark sent**. Every lead page also has a **WhatsApp kit
  panel** with the same Auto-send button and the manual steps.
  Leads that have the kit show a green "Kit sent" tag in All Leads.
  Pace yourself like a person — a few kits at a time, not 30 in one
  minute; that's what keeps your number safe.

## The Healthcare section (v1.5) — clinics live apart

The same CRM program also runs a completely separate
**Healthcare section** for clinics and small hospitals (the
Content365 play). It has its OWN database
(`vaani_healthcare.db`, filled by
`py vaani.py --vertical healthcare ...`), its own statuses,
remarks and kit log — clinic data and restaurant data never mix,
in either direction.

- Start it with **run-crm-healthcare.bat** (it opens on port 8770;
  the restaurant CRM stays on 8765 — both can run side by side,
  and each sidebar links to the other section).
- Everything works the same — dashboard, pipeline, call mode,
  follow-ups — over clinic leads only.
- The kit is the **Content365 kit**: an intro written for the
  doctor (it asks reception to pass it on, and carries the
  sample-posts link inside the message) plus his **Content &
  Trust Report**, generated by `clinic_report.py` into
  `clinic-reports/` (the CRM downloads that tool itself if it's
  missing). There is no brochure step — the kit is intro +
  report, in that order, via the same Auto-send button.
- The login popup reminder covers the restaurant section only.
- **Pipeline** — your whole funnel as a board, one column per stage.
  Drag a card to a new stage and it saves instantly.
- **All leads** — every lead, searchable, filterable by tier and
  status, sorted best-first. Change a status right in the list, or
  click a name for the full page.
- **Lead page** — details on the left, a timeline in the middle
  (remarks *and* every status change, recorded automatically),
  Call / WhatsApp / status / follow-up controls on the right.
- **Follow-ups** — overdue first, then today, this week, later.
- **Export CSV** (side menu) — everything, including statuses and
  follow-ups, in one file Excel can open. Your escape hatch, always.

## Rules the app follows

- **The CRM is the boss now.** Once a lead has a status in the CRM,
  Vaani never overrides it from the Excel tracker again (Vaani updated
  itself to v3.8 for exactly this). Use the tracker only as history.
- Marking **Not interested / Wrong number / Do not contact** here
  keeps that lead out of Vaani's scrape results, same as before —
  and Not interested leads still land in your win-back file
  (`vaani-not-interested.xlsx`) on the next Vaani run.
- Changing a lead back to any live status un-blocks it automatically.

## Follow-up popup at login (optional)

Double-click **`install-crm-reminder.bat`** once. From then on, when
you log in to Windows, **if** anything is due or overdue you get one
popup listing them; on quiet days you see nothing. The installer tests
itself with one popup at the end. (If the popup never appears at
login on your PC, tell me — the CRM does not depend on it; the
Dashboard shows the same list.)

## Safety

- Your lead databases, trackers and generated reports stay on this PC. The
  updater only downloads allow-listed code/UI files from the configured
  GitHub manifest; it never replaces databases or Excel trackers.
- Every day the CRM first opens, it refreshes a backup copy of the
  database: `vaani_master.db.crm-backup`. If anything ever goes
  wrong, that file is your leads.
- The CRM checks `update-manifest.json` at startup. When the version is
  newer, it downloads and verifies every listed CRM code/UI file, creates a
  `.pre-update` backup for replaced code, restarts once, and then opens the
  updated app. If the network is unavailable, it runs the current local
  version normally.

## If something looks wrong

- **CRM opens but shows no leads** → the files were unzipped into a
  new folder instead of your Vaani folder. Move them next to
  `vaani_master.db` and run again.
- **"Ports busy" message** → a copy of the CRM is already running.
  Use the one that's open, or close its black window first.
- **Browser didn't open** → the black window shows an address like
  `http://127.0.0.1:8765/` — type it into your browser yourself.
